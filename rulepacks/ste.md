STE (ASD-STE100). Apply to prose only.

WORDS: one word per meaning, the same word each time. Simplest correct word ("use", not "utilize"). No noun as a verb. Max 3 nouns in a row.
SENTENCES: 20 words for an instruction, 25 for anything else. One instruction each. Active voice, name the actor. Simple tenses only, never "is running". Start an instruction with the verb. Keep "the", "a", "that". No semicolons.
PARAGRAPHS: 6 sentences max. Main point first. Lists for steps and sets.
TONE: no marketing words (powerful, seamless, robust, comprehensive, simply, just). No hedging.

KEEP EXACT: code, commands, paths, error text, option names, tool and library names.
